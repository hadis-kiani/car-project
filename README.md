# نیترو سیتی | Nitro City — بازی ماشین‌سواری سه‌بعدی

یک بازی ماشین‌سواری سه‌بعدی کاملاً حرفه‌ای با موتور اختصاصی مبتنی بر Three.js — **رانندگی آزاد** + مسابقه، ۱۸ ماشین کمیاب، سه مسیر متفاوت (شهر مدرن، بزرگراه کویری، گردنه کوهستانی)، سه آب‌وهوا (آفتابی، شب، بارانی) و شخصی‌سازی کامل در گاراژ.

## حالت‌های بازی
- 🚗 **رانندگی آزاد** — بدون مسابقه و شمارش معکوس؛ گاز، ترمز، دنده عقب، ترمز دستی، دریفت، سه دوربین (تعقیب/کاپوت/کابین)، بازنشانی با R و چراغ با L
- 🏁 **مسابقه** — رقابت با ۷ حریف هوش مصنوعی، دور، رتبه و جایزهٔ سکه

## اجرا

بازی یک وب‌اپلیکیشن استاتیک است و به هیچ بیلد یا نصبی نیاز ندارد. کافی است پوشه را با هر سرور استاتیک سرو کنید:

```bash
python3 -m http.server 8080
# سپس در مرورگر باز کنید:
# http://localhost:8080
```

یا:

```bash
npx serve .
```

> نکته: مستقیم باز کردن فایل `index.html` با `file://` ممکن است به‌خاطر سیاست‌های مرورگر کار کند؛ برای تجربهٔ کامل (صدا و بافت‌ها) از سرور محلی بالا استفاده کنید.

## ویژگی‌ها

### ماشین‌ها (۱۸ مدل در ۷ کلاس)
اسپرت · ماسل · ریسینگ · سوپر اسپرت · هایپر · لوکس · کلاسیک — از مزدا میاتا تا بوگاتی شیرون و فراری ۲۵۰ جی‌تی‌او، با طراحی رویه‌ای بدنه (نبض، بال، ورودی هوا، چراغ‌های LED و کلاسیک).

### منوهای اصلی
- 🏁 **شروع مسابقه** — انتخاب مسیر، زمان روز، دور و سختی
- 🔧 **گاراژ** — شخصی‌سازی و ارتقای ماشین فعلی
- 🏎️ **نمایشگاه** — کلکسیون هر ۱۸ خودرو با فیلتر رده؛ خرید و انتخاب مستقیم از گرید
- 🏆 **رکوردها** — آمار رانندگی (مسابقه/برد/درصد برد)، بهترین دور و زمان کل هر مسیر، بهترین دریفت
- 🎖️ **دستاوردها** — ۱۲ دستاورد با نوار پیشرفت که از روی آمار واقعی شما محاسبه می‌شوند
- ⚙️ تنظیمات — کیفیت، دوربین پیش‌فرض، صدا، حذف پیشرفت

### گاراژ و شخصی‌سازی
- انتخاب و تعویض ماشین روی **پیش‌نمایش سه‌بعدی زنده** (Turntable با نورپردازی استودیویی)
- ۱۴ رنگ بدنه با ۳ پرداخت (براق / مات / مرواریدی)
- ۴ رینگ مسابقه‌ای × ۳ رنگ، ۳ نوع لاستیک (خیابانی / اسپرت / اسلیک) با تأثیر واقعی روی هندلینگ و ترمز
- زیرنور نئون ۶ رنگ
- ارتقای ماشین در ۵ سطح: موتور، لاستیک، ترمز — با تأثیر واقعی روی شتاب، سرعت، گریپ و ترمز
- خرید و مالکیت با سکهٔ بازی (ذخیره در LocalStorage)

### محیط‌ها و آب‌وهوا
- **خیابان نئون** — شهر مدرن با آسمان‌خراش‌ها، تابلوهای نئون، چراغ‌های خیابان، درختان و تابلوهای راهنمایی
- **بزرگراه غروب** — بزرگراه کویری با بیلبوردها و مزاها
- **گردنه البرز** — مسیر کوهستانی با ارتفاع واقعی، صخره‌ها و کاج‌ها
- 🌦️ **آب‌وهوا:** آفتابی ☀️ / شب 🌙 (چراغ‌های شهری) / بارانی 🌧️ (باران واقعی، خیابان خیس و انعکاس نور، مه غلیظ‌تر، گریپ کمتر)
- آسفالت خیس و براق در شب و باران، نوار نئون لبه‌بام روی برج‌ها

### گیم‌پلی
- رد لاستیک واقعی روی آسفالت هنگام دریفت، فیزیک آرکید روان: گاز، ترمز، دنده عقب، دریفت با Space (امتیاز دریفت و پاداش سکه)
- ۷ حریف هوش مصنوعی با رابربند (لاستیک‌خور) و سرعت مناسب پیچ‌ها
- دوربین سوم‌شخص تعقیبی با FOV داینامیک و دوربین کابین داخلی (فرمان چرخان)
- دورشمار، کیلومترشمار، تعویض دنده، RPM، رکورد بهترین دور، موقعیت زنده، مینی‌مپ
- شمارش معکوس، توقف (Esc)، مسیر اشتباه‌یار، صدای موتور/تایر/باد با Web Audio API (بدون هیچ فایل صوتی)

### کنترل‌ها
W/↑ گاز · S/↓ ترمز و دنده عقب · A/D یا ←/→ فرمان · Space ترمز دستی/دریفت · C تعویض دوربین (تعقیب/کاپوت/کابین) · R بازنشانی ماشین · L چراغ‌ها · Esc توقف · M بی‌صدا

روی موبایل: دکمه‌های لمسی روی صفحه نمایش داده می‌شود.

## ساختار پروژه

```
index.html          ساختار تمام صفحه‌ها (منو، گاراژ، نمایشگاه، رکوردها، دستاوردها، مسیر، HUD، نتایج)
css/style.css       سیستم طراحی کامل (راست‌چین، نئون، ریسپانسیو)
js/vendor/three.min.js   کتابخانهٔ سه‌بعدی (هماهنگ‌شده، در ریپو)
js/data.js          کاتالوگ ۱۸ ماشین، مسیرها، ارتقاها، ذخیرهٔ بازی
js/audio.js         موتور صوتی سنتزشده (Web Audio API)
js/carfactory.js    کارخانهٔ ساخت رویه‌ای ماشین‌ها + رینگ/لاستیک Canvas
js/world.js         جادهٔ روبونی، آسمان روز/غروب/شب، شهر/کویر/کوهستان
js/race.js          فیزیک مسابقه، هوش مصنوعی، دوربین، HUD، مینی‌مپ
js/freedrive.js     رانندگی آزاد (بدون مسابقه) با آب‌وهوا و بازنشانی
js/ui.js            منوها، گاراژ سه‌بعدی، نمایشگاه، رکوردها، دستاوردها، نتایج، ذخیره‌سازی
js/main.js          راه‌اندازی و تشخیص WebGL
assets/hero.jpg     تصویر پس‌زمینهٔ منوی اصلی
```

پیشرفت شما (سکه، مالکیت ماشین‌ها، ارتقاها، رکوردها) در `localStorage` مرورگر ذخیره می‌شود.
